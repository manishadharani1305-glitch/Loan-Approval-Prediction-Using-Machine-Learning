# Loan Approval Prediction Using Machine Learning

## Project Overview

This project predicts whether a loan application will be approved or rejected using Machine Learning techniques.

The system analyzes applicant details such as income, education, employment status, credit history, and loan amount to make predictions.

---

## Objective

The main objective of this project is to:

* Clean and preprocess loan applicant data
* Visualize important patterns in the dataset
* Train a Machine Learning model
* Predict loan approval status

---

## Dataset Information

The dataset contains applicant details such as:

* Gender
* Marital Status
* Education
* Applicant Income
* Coapplicant Income
* Loan Amount
* Credit History
* Property Area
* Loan Status

Dataset Source:

https://www.kaggle.com/datasets/altruistdelhite04/loan-prediction-problem-dataset

## Data Cleaning Steps

* Checked missing values
* Filled categorical missing values using mode
* Filled numerical missing values using mean
* Removed inconsistencies
* Converted categorical data into numerical format

## Machine Learning Model

The following algorithm was used:

* Decision Tree Classifier
